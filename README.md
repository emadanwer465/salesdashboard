# Sales Analytics Dashboard

## Overview

This dashboard analyzes sales performance, marketing impact, and seasonal trends.

## Features

* Sales by product category
* Marketing analysis
* Seasonal trends
* Return trends
* ROI tracking

## Installation

1. Install libraries

pip install -r requirements.txt

2. Run project

streamlit run app.py

## Tools

* Python
* Streamlit
* Pandas
